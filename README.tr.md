# Melih Güçlü

Piklo Studio’nun kurucusuyum. Afyonkarahisar’da web, mobil ve işletme yazılımları geliştiriyorum. Bir ürünün arayüzünü tasarlamaktan veri modelini kurmaya, SwiftUI ekranlarını yazmaktan yayına almaya kadar tüm sürecinde çalışıyorum.

[Piklo Studio](https://piklos.com) · [Portfolio](https://melihguclu.com.tr) · [info@piklos.com](mailto:info@piklos.com)
